### Εργαλεία (DatabaseScripts/)

Δημιουργήσαμε δύο κοινόχρηστα scripts που χρησιμοποιούνται από όλη την ομάδα:

- **`ParquetInspector.py`** — Εξερεύνηση του dataset χωρίς να φορτωθεί όλο στη μνήμη. Δείχνει schema, σταθμούς, εύρος ημερομηνιών, στατιστικά.
- **`DataFilter.py`** — Query builder με chainable filters για εξαγωγή συγκεκριμένου υποσυνόλου δεδομένων. Υποστηρίζει φιλτράρισμα ανά σταθμό, γραμμή, χρονικό εύρος και στήλες.

Και οι δύο διαβάζουν το αρχείο σε batches (5000 γραμμές τη φορά) για αποφυγή memory crashes σε μεγάλα αρχεία.

1. Φορτώνει τα δεδομένα του σταθμού αεροδρομίου μέσω `MetroDataQuery`

## 2. Επεξήγηση του Dataset

### Δομή

Το dataset είναι ένα αρχείο `metro_passengers.parquet` με καταγραφές από αισθητήρες στις πύλες (turnstiles) των σταθμών μετρό της Κοπεγχάγης. Κάθε γραμμή αντιπροσωπεύει μια **μέτρηση ανά λεπτό ανά πύλη**.

### Στήλες

| Στήλη | Περιγραφή |
|---|---|
| `timestamp` | Ακριβής ώρα μέτρησης (UTC, ανά λεπτό) |
| `stationId` | Αριθμητικός κωδικός σταθμού |
| `station` | Όνομα σταθμού |
| `system` | Γραμμή μετρό — `m1m2` (M1/M2) ή `m3m4` (Cityringen) |
| `ins` | Επιβάτες που **μπήκαν** στον σταθμό εκείνο το λεπτό |
| `outs` | Επιβάτες που **βγήκαν** από τον σταθμό εκείνο το λεπτό |
| `passengerNo` | Απλός μέσος όρος: `(ins + outs) / 2` |

### Ερμηνεία ins / outs στο Αεροδρόμιο

- **`ins`** = επιβάτες που **μπαίνουν στον σταθμό μετρό** αφού μόλις προσγειώθηκαν → πηγαίνουν στην πόλη
- **`outs`** = επιβάτες που **βγαίνουν από τον σταθμό μετρό** στο αεροδρόμιο → πρόκειται να αναχωρήσουν με πτήση

### Το `passengerNo` — Διευκρίνιση

Παρά ότι το αρχικό documentation το περιέγραφε ως "rolling average", η ανάλυση έδειξε ότι είναι ακριβώς:

```
passengerNo = (ins + outs) / 2
```

Αυτό επαληθεύτηκε με **100% ακρίβεια** σε όλες τις 1,051,200 γραμμές — δεν υπάρχει καμία εξαίρεση. Συνεπώς δεν προσθέτει νέα πληροφορία και μπορεί να παραλειφθεί σε μοντέλα όπου χρησιμοποιούμε ήδη `ins` και `outs`.

## 3. Ανάλυση Dataset — Airport Station

### Βασικά Στατιστικά

Μετά από αφαίρεση 137,660 μηδενικών εγγραφών (αισθητήρας ανενεργός / νυχτερινές ώρες):

| | ins | outs |
|---|---|---|
| Παρατηρήσεις | 913,540 | 913,540 |
| Μέσος όρος | 10.1 | 11.6 |
| Τυπική απόκλιση | 7.4 | **17.4** |
| Ελάχιστο | 0 | 0 |
| Μέγιστο | 115 | **190** |
| Σύνολο (2 χρόνια) | ~9.2 εκατ. | ~10.6 εκατ. |

**Παρατήρηση:** Τα outs έχουν πολύ μεγαλύτερη τυπική απόκλιση (17.4 vs 7.4), που σημαίνει ότι οι αναχωρήσεις είναι πιο "εκρηκτικές" — πολλοί επιβάτες φτάνουν μαζί στο αεροδρόμιο πριν από συγκεκριμένα δρομολόγια.

### Ωριαίο Μοτίβο

Τα outs εμφανίζουν **δύο κορυφές** την ημέρα — ένα εύρημα που κρυβόταν πίσω από τους μέσους όρους:

|---|---|---|---|
| 04:00 | 1.2 | 13.7 | Πρωινές πτήσεις — αναχώρηση |
| 05:00 | 1.7 | 14.2 | Πρωινές πτήσεις — αναχώρηση |
| 06:00 | 2.7 | **17.2** | **Κορυφή πρωινών αναχωρήσεων** |
| 07:00 | 8.0 | 15.6 | |
| 12:00 | 12.5 | 13.7 | Μεσημεριανή κίνηση |
| 15:00 | 13.1 | 17.5 | Απογευματινές πτήσεις |
| 16:00 | 13.9 | **17.6** | **Κορυφή απογευματινών αναχωρήσεων** |
| **17:00** | **14.4** | 15.6 | **Κορυφή αφίξεων** |

Τα ins κορυφώνονται στις **17:00** — συνεπές με απογευματινές αφίξεις πτήσεων. Τα outs κορυφώνονται **δύο φορές**: πρωί (06:00) και απόγευμα (16:00) — αντικατοπτρίζοντας τα δύο μεγάλα κύματα αναχωρήσεων του αεροδρομίου.
